# Item Catalogue

This is the item-level archive for THE HOLLOW REALMS. Each identified named weapon and Rune has an individual dossier. Categories without a confirmed item identity have category pages that list what is known and what must not be guessed.

## Status key

- **Source-backed reference:** named object from existing Adventure Time material; game implementation still needs approval.
- **Proposal:** shown in a design reference or discussed as a possible game item; balance/rules are not final.
- **Category only:** a reward/equipment category exists as an idea, but no exact named item has been approved.
- **Open decision:** details are unknown and must remain blank until decided.
- **Archived concept:** visual exploration only; not a real item in the catalogue.

## Item dossier standard

Every new named item must document:
1. Exact display name, type and source.
2. Visual identity and icon requirements.
3. Equipment slot or use context.
4. Gameplay effect and formula (or mark it open).
5. Compatibility, stacking and restrictions.
6. Rarity, upgrade path and economy role (or mark them open).
7. Acquisition sources and Auto Hunt eligibility.
8. Player-facing short description and full detail text.
9. Asset source, creator, permission and repository path.
10. Status and decisions needed before implementation.

Do not fill unknown details with invented Adventure Time canon, arbitrary stats or made-up acquisition routes.
