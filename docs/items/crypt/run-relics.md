# Hollow Crypt Run Relics

**Category record** · **Status:** temporary system concept; no individual Relic names approved

## Identity

| Field | Detail |
|---|---|
| Mode | The Hollow Crypt |
| Type | Temporary passive run effect |
| Lifetime | Current Crypt run only |
| Permanent inventory item | No, under the current concept |
| Equipment slot | None |
| Individual names/effects | Open |

## How Run Relics differ from Runes

| Equipment Rune | Crypt Run Relic |
|---|---|
| Permanent character equipment | Temporary run effect |
| Uses the character's Rune slot | Does not use an equipment slot |
| Remains in inventory when unequipped | Expires when the Crypt run ends |
| Candidate Auto Hunt reward | Not a permanent Auto Hunt inventory reward |

## Proposed role

Run Relics may give a temporary offensive, defensive, healing, sustain or encounter-utility effect. A possible room-milestone reward is a choice among several offers, but offer count, frequency, rarity and stacking are not decided.

## Required dossier for every future Relic

Each approved Run Relic needs a unique name, effect, trigger timing, affected characters, duration, stacking rule, interaction with equipment Runes, icon and acquisition room.

## Implementation boundary

Do not give these effects permanent inventory ownership or place them in the Rune equipment slot. Do not invent individual Relic names until the Crypt reward design is approved.
