## Known direction

Mana-restoring consumables have been discussed because Mana regeneration is intentionally slow. Basic Attack is free, so a character with no Mana can still Attack or Defend.

No exact Adventure Time item, name, icon, healing amount or rarity has been approved.

## Gameplay fields still open

- Flat or percentage Mana restoration.
- Target: self, one ally or team.
- Whether use is allowed during combat.
- Whether the item can be used at zero Mana.
- Use limit per turn/room/run.
- Shop price, drop source, rarity and stack size.
- Whether Max Mana affects percentage-based restoration.

## Player-facing text draft

A consumable that restores Mana. The exact amount and valid targets are shown in its final item details.

## Implementation boundary

Do not introduce Energy. This category restores Mana only and does not define passive Mana regeneration.
