# Accessory Catalogue Status

## Confirmed equipment rule

Each character has two accessory slots: Accessory 1 and Accessory 2. No Headgear slot exists.

Accessories may eventually provide direct stat bonuses or passive utility effects, but no exact source-backed Adventure Time accessory has been approved for the canonical catalogue yet.

## Archived shape explorations

The old generic shape sheet contains these neutral placeholders:
- Pendant
- Ring
- Bracelet
- Brooch
- Charm
- Buckle
- Medallion
- Watch

These labels describe silhouettes only. They are not approved item identities, do not establish Adventure Time canon objects, and must not be added to loot tables, inventory definitions or crafting recipes.

## How to add an accessory

First identify a real Adventure Time object and record a reliable source reference. Then create one item dossier containing its exact source name, owner/association, visual details, proposed slot, possible game effect, compatibility, rarity, upgrade and acquisition status. Any effect is a game proposal, not franchise canon.

## Rules still open

- Whether two identical accessories can be equipped together.
- Whether accessories are character-specific.
- Stat and passive-effect list.
- Rarity, upgrades, materials and drop rates.
- Source-backed launch catalogue.

Until these decisions and source research exist, the two slots remain valid but the accessory item list remains empty.
