# Armor Slot & Catalogue Status

## Confirmed equipment rule

Every character has one Armor equipment slot. The five-slot layout is Weapon, Armor, Rune, Accessory 1 and Accessory 2. There is no Headgear slot.

## Current catalogue status

**Category only.** No exact armor item name or approved Adventure Time armor object has been selected yet.

Potential stat families discussed for armor are HP, DEF and resistance. No armor type, appearance, class restriction, set bonus, rarity, upgrade level or numerical value is approved.

## What is required before adding armor

For each armor item, create an individual dossier that records:
- Exact Adventure Time object name and source episode/material.
- Source-backed appearance and materials.
- Which parts of a character it covers.
- Item icon and portrait/battle readability requirements.
- Base stats and any passive effect.
- Class/character restrictions.
- Rarity and upgrade path, if approved.
- Acquisition source and whether the reward route is allowed.
- Creator, permission and asset path.

Do not invent helmets, armor sets or generic fantasy armor to fill this slot. The old accessory/headgear drawings do not create armor items.
