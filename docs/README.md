## Status labels

- **Confirmed direction:** a design rule explicitly selected in the project discussion.
- **Source-backed reference:** an existing Adventure Time object or character documented with a reference link; this does not mean the game implementation is approved.
- **Proposal:** a concrete example that still needs balancing or approval.
- **Open decision:** information is not known yet; do not invent it in implementation.
- **Archived concept:** kept for history, not an active reference or approved asset.

## Contribution rule

When adding a new item, create an individual dossier using the catalogue's item template. Record the source, visual identity, category, slot, gameplay effect, acquisition boundary, rarity, upgrade behavior, UI presentation and unresolved decisions. Never fill an unknown field with invented canon or an arbitrary statistic.
